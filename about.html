About QuizToBBZip

A free tool made by a teacher, for teachers who are tired of retyping quizzes into their LMS.

Many schools write quizzes in Word or Google Docs, but Schoology, Canvas, Moodle and Blackboard all want questions in their own formats. QuizToBBZip reads an ordinary quiz document, works out the questions, options and correct answers, and builds a Blackboard-format test package that these systems can import.

What it does

  • Reads Word (.docx), .txt and .md quizzes, including Word’s automatic numbering, tables, pictures and equations.
  • Finds the answers from a key, a marked option, an Answer: line, or the formatting you used.
  • Turns equations into plain text every LMS can show, shares diagrams between questions, and balances the answer letters.
  • Gives you a check table first, so you can see what it understood before you import.

Is it AI?

No. It is ordinary, rule-based code that runs in your browser. The same input always gives the same output, and nothing is sent anywhere.

Source

The code is a single set of plain files: index.html, engine.js, app.js and style.css. It is a JavaScript port of a Python converter used for weekly classroom quizzes.
