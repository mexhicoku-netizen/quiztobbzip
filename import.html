Import steps

Import the file ending _Blackboard.zip exactly as it is. Do not unzip it. (If you downloaded “everything”, unzip the outer download first and take the _Blackboard.zip from inside.)

Tested by the author in Schoology. The Canvas, Moodle and Blackboard steps below follow each vendor’s documented import for Blackboard-format files; try a short quiz first and check the answers after importing.

Schoology

  1. Open your course, then Add Materials → Add Test/Quiz. Give it a title and click Create.
  2. Click Add Question → Import Test/Quiz.
  3. Choose Blackboard as the format and click Next.
  4. Choose the _Blackboard.zip file and click Import.
  5. Open the quiz and compare the correct answers with the key from the download.

Canvas

  1. In your course, open Settings → Import Course Content.
  2. Content Type: Blackboard 6/7/8/9 export .zip file.
  3. Choose the file, select All content, and click Import.
  4. The test arrives as a quiz and a question bank. Check it in Quizzes.

Moodle

  1. Open the course and go to the Question bank, then Import.
  2. File format: Blackboard.
  3. Upload the _Blackboard.zip file and click Import.
  4. Add the imported questions to a quiz from the question bank.

Blackboard Learn

  1. In your course, open Course Tools → Tests, Surveys, and Pools → Tests.
  2. Click Import Test, browse to the _Blackboard.zip file and submit.
  3. Deploy the test in a content area when you are ready.

If something looks wrong

  • Open _Check.txt from the download: it lists what was found for every question and any warnings.
  • Answers look different from your paper copy? They were shuffled for an even A–D spread. The _Key.txt file has the order of the test. Untick Shuffle to keep your order.
  • A picture is missing? Turn off Pack pictures under More options, import, and add the saved figures/Q##.png files by hand.
  • As a last resort, _Schoology.txt is the whole quiz as text with the correct answers marked *, ready to paste or retype.
